# Jueguito (Brainrot WorldBox)

Un juego estilo "God Game" similar a WorldBox, pero con personajes y mecánicas basadas en la cultura de internet y el "brainrot" moderno (TikTok memes, personajes polémicos, etc.).

## 🧠 Características
- **Personajes Brainrot:** Spawnea NPCs basados en memes actuales.
- **Poderes Divinos (o Cursed):** Destruye o altera el mundo usando habilidades basadas en memes de internet.
- **Simulación:** Observa cómo interactúan y sobreviven.

## 🚀 Instalación y Desarrollo
Este proyecto utiliza Vite + TypeScript. 

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

## 🛠️ Tecnologías
- HTML5 Canvas
- TypeScript
- Vite
