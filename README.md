# Jueguito (Brainrot WorldBox)

Un juego estilo "God Game" similar a WorldBox, pero con personajes y mecánicas basadas en la cultura de internet y el "brainrot" moderno (TikTok memes, personajes polémicos, etc.).

## 🧠 Características
- **Personajes Brainrot:** Spawnea NPCs basados en memes actuales (Skibidi Toilet, GigaChad).
- **Epstein Island:** Crea zonas en el mapa que vuelven locos a los NPCs que entren allí.
- **Poderes Divinos (o Cursed):** Destruye o altera el mundo usando habilidades basadas en memes de internet, como la *Cancel Culture* o el *Ratio Nuke*.

## 🚀 Instalación y Desarrollo
Este proyecto utiliza Vite + TypeScript + Phaser.js.

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

## 🛠️ Tecnologías
- Phaser.js (Motor 2D)
- TypeScript
- Vite
